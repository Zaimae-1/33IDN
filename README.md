# 33IDN

Fondasi project portfolio angkatan. Halaman aplikasi sengaja kosong agar desain dan kontennya bisa ditentukan nanti.

## Menjalankan project

```bash
npm install
npm run dev
```

Pemeriksaan:

```bash
npm run build
npm run lint
```

## Dependensi

- React + Vite + TypeScript
- Tailwind CSS melalui `@tailwindcss/vite`
- React Router (`react-router-dom`)
- Motion (`motion`)
- GSAP + ScrollTrigger (`gsap`)
- Lenis (`lenis`)
- Three.js (`three`), React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- Lucide React (`lucide-react`)

Folder di `src` sudah disiapkan untuk assets, components, sections, three, animations, data, hooks, layouts, pages, types, dan utils. File `.gitkeep` hanya menjaga folder kosong tetap ada di Git.
